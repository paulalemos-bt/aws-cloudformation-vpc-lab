# AWS CloudFormation – VPC Lab

## Descrição
## Este projeto demonstra a criação automatizada de infraestrutura na AWS utilizando CloudFormation.

## Recursos Criados
 - VPC
 - Internet Gateway
 - Subnet Pública
 - Subnet Privada
 - Security Group com acesso SSH
 - Instância EC2 t3.micro
 - Bucket S3

## Objetivo
## Praticar Infraestrutura como Código (IaC) utilizando AWS CloudFormation.

## Tecnologias
 - AWS CloudFormation
 - Amazon EC2
 - Amazon VPC
 - Amazon S3

## Aprendizados
## Durante este laboratório pratiquei:
 - Criação de arquitetura de rede na AWS
 - Automação de infraestrutura
 - Organização de templates YAML
